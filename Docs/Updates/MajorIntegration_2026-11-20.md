# 大型更新与整合 — 2026-11-20

本次将 Campus_XR 的阶段三流程、交互、场景、特效音效及多语言 UI 汇总为一个可追溯的大型更新。以下描述为最终实现；早期验证报告中已被替代的摇杆护送、B 键模式切换、物品归还、保险销永久保持拔出等行为，不再代表当前版本。

## 1. 更新范围与来源

- Unity 保持 **2022.3.62f3**；面向 Windows PC VR、Quest 3、Quest Link / Air Link、OpenXR，不改为 Android 独立运行。
- 主场景：`Assets/Scenes/TeachingBuildingCampusXR.unity`。本次同时保留桌面场景此前的建模与特效改动。
- 本地更新基于 `671dd08`，包含此前尚未进入 main 的 `d2800cb` UI 更新、`05fe6ea` UI/人物整合，以及 `671dd08` 校园模型与材质改进。
- Effects 来源为 `4bad4860a73045cc87137ed29d0a929fa8641f21`，涉及 `a19a335` 烟火布局与 `4bad486` 音效。按对象 ID 合并，保留原有 XR 场景的本地调整，详见 [特效整合记录](../EffectsImport_20261120.md)。
- 不包含新的 Windows 可执行文件或 ZIP。`Phase2_Deliverables` 内现有包仍为早期版本，不能用于验证本次新功能。

## 2. 完整疏散路线

保持六个主节点，在第六步纳入出口再次灭火：

1. **401 启动火警**：从四楼 401 后方中央开始，在教室内操作火警按钮。
2. **准备防烟毛巾**：进入对门洗手间，拿取毛巾、用水龙头沾湿、举起遮住口鼻。
3. **A 侧避火改道**：经 A 侧楼梯下至三楼，发现下行火势后进入三楼走廊。
4. **B 侧灭火并下楼**：横穿走廊至 B 侧，取得灭火器，拔销，对准根部灭火，再沿 B 侧楼梯下至二楼。
5. **安置轮椅人物**：B 侧二楼下行楼梯断裂，进入走廊护送轮椅人物到安全房，按检查点确认安置。
6. **出口灭火、撤离和报警**：经 A 侧到一楼，扑灭正门三簇火焰，前往室外集合点，模拟拨打 999，进入复盘。

`CampusRouteAFlow` 记录节点与位置检查；未完成必要条件不能完成电话节点。复盘记录交互和检查点，不推断真实应急能力、注视或危险识别。

## 3. 起点与开局流程

- 起点移至 401 后方中央，无需按 F4。
- 选择语言到确认开始演练期间，固定虚拟角色位置。
- 语言选择、流程介绍固定在起点前方，不随头部视线移动。
- 射线悬停与点击具有颜色、描边、短暂确认反馈；支持设备时提供触觉反馈。
- 正式开始后清除开局显示内容，恢复正常传送与转向；电话和复盘仍可建立后续界面。

## 4. 手部模型与统一物品系统

- 用可随控制器输入弯曲手指的手部视觉模型替换控制器外观，附带皮肤及袖口材质。
- 手部模型不带阻挡射线的实体碰撞，也不代表原生光学手势追踪。
- 毛巾和灭火器均为**左手持有**，右手保留传送及交互。
- **左 X** 循环：空手 → 毛巾 → 灭火器 → 空手，跳过尚未取得的物品。
- 只有空手可拾取灭火器；取消强制归还步骤。收起毛巾保留湿润状态，重新装备时处于放下状态。
- 物品切换立即停止喷射并中断当前连续灭火计时。

## 5. 毛巾操作与烟雾通行检查

- 对准毛巾或水龙头按右 A 拾取、沾湿。
- 装备湿毛巾时，左扳机点按切换举起/放下，用于表示遮住口鼻，并避免遮挡主要视野。
- 四楼通往 A 楼梯的烟雾检查区覆盖 X=-12.25 至 -9.5、Z=-1.65 至 1.65，避开洗手间取物路线。
- 必须同时满足**已装备、已沾湿、已举起**，才允许传送进入或跨越检查区。
- 检查人物脚下到目标落点的完整线段，不能把落点直接选在另一端来跳过检查。
- 区内放下或切走毛巾后，禁止继续深入，但允许退回进入前的安全侧；重新举起后恢复通过。
- 此项约束针对虚拟传送，不阻止真实房间中的身体走动，也不模拟烟雾伤害。

## 6. 灭火器操作与喷射修复

- 右手射线对准黄色保险销，按 **A** 拔销。
- 左手喷嘴对准火焰根部，按住**左扳机**喷射；右扳机仍可传送。
- 每簇火必须连续命中 **3 秒**，才一次性扑灭；中断、偏离、改换目标或切换物品均重置未完成计时。
- 圆形进度及倒计时显示实际连续喷射进度。
- 修复第一次喷射不出现粒子的情况：启动时主动发射粒子，并保持正确的模拟、寿命与清除状态。
- **每次重新装备灭火器，保险销复位，必须再次拔出**；重复更新同一个已装备状态不会无故复位。
- 装备、失焦或丢失追踪后，需要释放扳机再按下，防止恢复时误喷。

## 7. 火焰阻挡规则

- 火焰采用解析区域阻止传送射线及相关通行确认，不恢复旧版实体火焰碰撞盒。
- 喷射目标仍为火焰根部容差区域，避免大型实体碰撞体阻挡灭火瞄准。
- 灭火后停止粒子、光照及相关音效，释放对应火区限制。
- 保留楼层高度判定，避免下层火焰误阻挡上层地板。

## 8. 一楼正门三簇火焰

- 场景持久保存三个独立火源，位于正门前 X=-1.1、0、1.1，Z=-7.2。
- 每簇独立执行连续 3 秒的根部灭火规则。
- 到达出口附近时提醒按 X 切换灭火器，随后引导重新拔销及逐簇灭火。
- **三簇全部扑灭后才开放整个出口**，灭掉一簇不能从空隙传送穿过。
- 火区限制同时检查可见射线和脚下至落点路径，不影响二楼通路。
- 未清空出口不能完成集合点电话节点；扑灭后继续原来的集合、999 与复盘流程。

## 9. 轮椅人物与护送交互

- 在二楼走廊放置轮椅及坐姿人物，并加入第五节点的必要流程。
- 第一次对准按 A 开始护送时，玩家自动站到轮椅后方，双方初始朝 B 侧。
- 护送时保持右手射线传送；没有左摇杆连续移动，避免该方案引起的晕动不适。
- 轮椅保持约 1.05 米间距，避免玩家与模型重合。
- 护送期间关闭轮椅自身阻挡碰撞，射线也明确跳过活动轮椅；停止后恢复原碰撞状态。
- 验证玩家和轮椅的同层支撑、落点空间、扫掠通路与火区限制；墙体和关门继续阻挡。
- 护送时暂收物品，暂停/完成后恢复原装备。恢复灭火器同样需要重新拔销。

## 10. 安全房确认与朝向

- 进入安全房不会自动完成任务。右手射线对准安置点按 A 确认。
- 检查玩家确已进入房间、正在护送、通路畅通，并与最终停放点保持至少 0.85 米间距。
- 确认后轮椅自动移动到 `(3.75, 3.65, -5.5)`，面朝房门（+Z），结束护送并推进第六步。
- 确认标记在内墙前方 `(3.75, 4.6, -5.95)`。
- 标记灰色表示条件未满足，绿色表示可安置；射线有效悬停时变金色并出现脉动光环。
- 普通传送射线显示期间也能提前看到高亮；失焦、失去追踪或被实体遮挡时取消高亮。
- 完成时显示“已安置”和蓝色地面扩散光环；抬高完成文字，避免被人物遮住，并停止接受重复确认。

## 11. 二楼安全房清理与双开门

- 删除安全房内两张桌面及两条桌腿，保留墙、窗、地面等结构。
- 检查点与停放点分阶段向内移动，最终靠内墙布置。
- 实际墙洞从约 **1.5 米扩大到 2.4 米**；两侧墙体、踢脚线、饰面、门框、门楣及碰撞同步调整。
- 改为联动双开门：对准任意门扇按 A 同时开关两扇门。
- 两扇门向安全房内部打开，避免打开后占用走廊轮椅靠近空间。

## 12. 护送进门判定修复

- 原先预测落点使用头部朝向，侧头会使轮椅偏入门框；现优先按传送方向安排轮椅位置，近墙时采用经过校验的已有朝向备选。
- 二楼门中心在 X=4.1，停放点在 X=3.75，原来单条对角扫掠易碰侧墙。
- 跨越该门口时可通过真实门洞中心的支撑点分段检查，所有分段仍检查墙、门、火区及地面。
- 未关闭物理门碰撞，未允许穿墙。

## 13. 烟雾高度与楼梯穿层修复

- 将走廊烟雾改为天花板薄层，移除下层浓雾，关闭持续上升、垂直扰动、尺寸增长与旋转扩张。
- 当前烟雾限制在本层地面上方约 **2.45–3.25 米**。
- 楼梯烟雾按各楼层与局部梯段分别收束范围，降低密度，不作为贯穿楼层的大体积烟柱。
- 烟雾 shader 支持独立世界空间边界裁切与边缘淡出，避免 billboard 边缘越过上层楼板。
- 裁切默认关闭，只有设置边界的烟雾渲染器启用，保留其他材质使用方式。
