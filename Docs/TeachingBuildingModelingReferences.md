# 教学楼建模参考与改进建议

查阅日期：2026-10-02。以下结论来自公开项目说明、仓库文件、场景截图、资源商店页面和官方建模文档。当前任务是学习场景建模方法；本文给出后续细化方案，未将这些项目的模型或插件导入本工程。

最接近我们用途的参考是 INFERNO：根据真实教学楼平面图制作 Blender 模型，再放进 Unity 做 VR 消防练习。学校模块化场景包则更适合研究墙、门窗、房间和道具的拆分。两者结合，可以把当前四层灰盒逐步细化成有学校特征的可漫游场景。

| --- | --- | --- | --- |

INFERNO 的可进一步查看入口：[建筑资源目录](https://github.com/ISTE-VIT/Inferno/tree/main/Assets)、[教学楼地面层 FBX](https://github.com/ISTE-VIT/Inferno/blob/main/Assets/TT_Gfloor.fbx)、[教学楼 Prefab](https://github.com/ISTE-VIT/Inferno/blob/main/Assets/TT_prefab.prefab)、[Unity 版本](https://github.com/ISTE-VIT/Inferno/blob/main/ProjectSettings/ProjectVersion.txt)、[渲染及 XR 包配置](https://github.com/ISTE-VIT/Inferno/blob/main/Packages/manifest.json)。其 README 建模截图能看到平面图底图与沿图搭建的墙体。FBX 导入配置的 globalScale 为 1，未自动生成碰撞体；这提醒我们，导入视觉模型后仍要单独处理玩家碰撞。

当前原型包含 2947 个对象、19 种材质，尚无图片纹理。可漫游的空间、连续楼梯、贯通电梯井和疏散设施已经建立。下一轮建模应集中在重复部件的模型质量、材质和重点房间，而不是继续扩大校园范围。

| 部件 | 建议的制作与复用方式 | 下一轮可见改进 |
| --- | --- | --- |
| 墙体 | 分为实墙、门洞墙、窗墙、转角和墙顶收口；使用统一基准尺寸与对齐点 | 形成完整门洞、窗台、墙厚和墙脚，减少拼接缝 |
| 门窗 | 门框与门扇分开；门扇轴心放铰链处；窗框、窗台和玻璃分开 | 增加少量边缘倒角和真实框厚；重复实例共用网格与材质 |
| 标准楼层 | 精做一个上层结构，组合走廊、房间、电梯厅和楼梯入口，再复用到二至四楼 | 用门牌、告示板和少量家具变化区分楼层；一楼单独处理入口大厅 |
| 双跑楼梯 | 单跑、中间平台、侧梁和扶手分别建模；复用单跑网格，保持两端标高准确 | 台阶连续、扶手完整、踏步边缘可辨认；视觉网格与通行碰撞分别检查 |
| 电梯 | 全楼一套井道与轿厢；每层复用厅门、门框、按钮、显示器和停用牌 | 补齐金属门边、门缝和按钮凹凸；电梯内外结构上下对齐 |
| 教室 | 做课桌椅组、讲台、白板和公告栏；重点完成 201/401 | 增加教学楼识别度；家具位置保持门口和过道畅通 |
| 消防设施 | 消防柜、灭火器、报警按钮、应急灯和出口牌使用独立 Prefab | 保持外观比例和放置高度一致；给队友留下独立交互对象 |
| 材质与灯光 | 墙漆、地砖、木材和金属采用少量可平铺纹理；静态环境评估烘焙光照 | 先改善第一人称视角中的墙地面与明暗，再补远处小道具 |

建议沿用 1 Unity 单位约等于 1 米、层高 3.6 米的比例。以 0.5 米为主要搭建网格，门窗细节使用更细网格；墙和门窗模块的轴心、接缝位置保持一致。尺寸或模块化调整不得挤占已经验证过的走廊、楼梯与门口空间。

可采用以下制作顺序：

1. 从现有布局整理一张标准层平面图，标出教室、走廊、楼梯、井道和出口；在模型制作软件中按比例使用底图。
2. 用 Blender 制作墙、门窗、单跑楼梯、平台和电梯厅模块，做好轴心、法线与基础 UV；也可用 ProBuilder 在 Unity 内制作结构网格。
3. 导出 FBX，检查导入后的比例和旋转，将视觉模型、碰撞体与交互脚本组合为 Prefab。结构模块共用材质，避免每个实例产生新材质。
4. 先精做一层走廊、电梯厅、楼梯入口和 401 教室，用现有玩家实走；通过后再复用到其他楼层。
5. 添加墙漆、地砖等纹理和灯光，检查文字可读性、玻璃遮挡、门动画及两条疏散路线，再用目标 VR 设备测性能与移动。

固定建筑可以在确认无需单独编辑后评估合并网格；门扇、按钮和消防交互物保留独立对象。性能优化以 Unity Profiler 和目标设备数据为依据，对象数量本身不能说明是否达标。

推荐优先学习 INFERNO 的“平面图到建筑模型”流程、学校场景包的模块分类，以及 ProBuilder 的楼梯构造。当前工程最有价值的下一步，是完成一个有材质和细节的标准层，再将它复用成四层教学楼。
