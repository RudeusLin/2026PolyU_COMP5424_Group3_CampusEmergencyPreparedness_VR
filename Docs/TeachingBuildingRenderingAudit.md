# 教学楼渲染检查与修复

本次继续更新 `TeachingBuildingRefined.unity`，保持四层教学楼、两条疏散通道和现有交互入口。

| 已确认的问题 | 原因与修复 |
| --- | --- |
| Game 窗口中的细边缘和文字显得模糊 | 用户截图显示 Scale 2×，已有画面被放大。相机未绑定低分辨率 RenderTexture，也未使用景深；查看时改为 1× 并使用固定渲染分辨率 |
| 屋顶和广场出现弧形波纹 | 实际渲染对比中，关闭颜色纹理、凹凸细节或光照图均无法消除，关闭太阳实时阴影后消失。太阳的 Bias/Normal Bias 从 0.035/0.12 调为 0.05/0.4，正常投影继续保留 |
| 树木和部分家具出现塑料般的高光 | 导入器只给有纹理的材质设置 Metallic/Smoothness。改为所有材质均设置，并为叶片、草地、树皮使用较低光滑度 |
| 重建材质可能继承透明或自发光状态 | 复用 Material 时未清理旧 Shader、Blend、ZWrite、Queue 和关键字。导入前恢复不透明基线，再应用透明或灯具设置 |
| 禁用文字初始化组件后文字丢失 | OnDisable 销毁了 Renderer 正在使用的共用材质。改为 OnDestroy 释放，禁用时只取消字体图集事件订阅 |
| 文字颜色偏亮 | 自定义文字 Shader 未将 TextMesh 顶点颜色从 sRGB 转到线性空间。补充颜色转换，保留透明混合和深度遮挡 |
| 室内灯光穿墙、照明缺少层次 | 原来使用无阴影点光和较强环境光。室内光改为带软阴影的烘焙照明，并加入间接光、光照探针、天空与烘焙反射 |
| 灯具发绿、白墙过亮 | 原始 Glow 材质使用绿色调，自发光与点光叠加后反射过强。调整为中性白光，并降低光源、墙面反射率和自发光强度 |
| 光照图中的细长构件接缝不稳定 | 倒角网格缺少 UV2，极薄的面展开后不足一个像素。为结构盒体分别保留六个面图表和留白；小件、曲面与倒角家具接收光照探针，同时参与静态阴影计算 |
| 两侧出口的窄墙柱出现 UV 采样警告 | 烘焙后直接调用 Unity 的重叠诊断，定位到宽 45 厘米的墙柱。窄柱改用光照探针；较宽的墙面保留光照图，最终烘焙重叠检测为零 |
| 光照缓存可能使用旧版 UV 和材质 | 新网格 UV、材质与天空设置原来在烘焙之后才保存。改为在烘焙前保存场景与资源，确保导出的烘焙输入与实际渲染资源一致 |
| 表面平整、木纹重复过于机械 | 增加原创颜色与线性细节图，细节图分别控制遮蔽、高度和光滑度；木纹加入不规则扰动，Shader 用世界坐标和表面梯度保持凹凸尺度 |
| 离线玻璃和文字叠加顺序错误 | 原来按几何类型批量绘制透明对象。改为玻璃、烟雾和文字统一按视深由远到近绘制，透明批次关闭深度写入；表面纹理使用 mipmap |
| 楼层剖面中出现悬空吊顶格栅 | 吊顶细节原来放在教室节点下，屋顶开关无法隐藏它们。保存完整教室 Prefab 后，将场景中的吊顶、灯具及悬挂设备加入屋顶开关；逐一比较世界矩阵，保证几何和现有光照不变 |

照明逻辑集中在 `TeachingBuildingLighting`，布局与材质参数继续来自共享 JSON。生成器、导入器和渲染检查各自负责一种工作，复用相同尺寸的网格及同类材质，不增加新的渲染管线或包依赖。

本次清晰度修复直接复用导入器已有的逐光源初始化，只调整太阳的实时阴影参数，并同步已保存场景中的同一光源，避免新建渲染组件或改动全局质量配置。沿用既有材质、模型和烘焙数据；通过独立工程的同视角渲染验证偏移量，符合 KISS/YAGNI，并保证重建后的参数与交付场景一致。

验证包含 Unity 实际烘焙和六个视角的截图、两条疏散路线的物理采样、保存后重新加载的光照与反射资源、Shader 编译、文字重复初始化及 Prefab 加载。文字的像素检查比较目标颜色，检查禁用组件前后的画面一致性，并要求被不透明墙挡住的文字贡献零像素。最终结果以 `Docs/Previews/Refined/ModelValidation.txt` 为准。

VR 头显帧率和正式 XR 移动未测试。离线 HTML 的光照仍经过简化，Unity 截图用于判断实际材质和光照效果。
