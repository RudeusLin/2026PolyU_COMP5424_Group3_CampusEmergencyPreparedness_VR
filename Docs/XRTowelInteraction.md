# XR 左手毛巾与遮挡口鼻动作

毛巾改为左手持有，右手仍用于交互和传送。

| 操作 | 按键 |
| --- | --- |
| 拿取毛巾 / 使用水龙头润湿 | 右手 A，保持原操作 |
| 抬起湿毛巾表示挡住口鼻 | 打湿后按一次左手扳机 |
| 放下到左手 | 再按一次左手扳机；无需按住，松开不改变状态 |
| 传送 | 右手扳机，抬毛巾时也可使用 |
| 归还毛巾 | 右握持键，先松开右扳机 |

干毛巾不能抬起，按键会提示先打湿。抬起和放下约用 0.2 秒过渡。抬起姿态位于头显前方 32cm、左侧 6cm、下方 24cm，并根据模型渲染边界将毛巾顶部限制在视线中心下方至少 12cm。姿态跟随头显朝向，包含抬头、低头和侧倾；保留中央视野。这是遮住口鼻的表达动作，不会将模型紧贴眼睛。未抬起时继续跟随真实左手位置和朝向。

失去应用焦点或左手追踪时暂时隐藏毛巾并放下；恢复后重新按左扳机切换状态，恢复追踪本身不会抬起毛巾。归还会恢复原位置、碰撞、可见性及干燥状态。抬起/放下不会改变润湿状态，也不新增防烟数值或伤害机制。

`CampusXRInventory.cs` 负责持有、输入、姿态和可见性；`CampusXRSceneBuilder.ConfigureInventory` 为场景和预制体配置左手挂点；`CampusXRFeedback.cs` 显示持有状态与按键说明。桌面版 CampusTowel 逻辑不变。
