# 跨楼层火区隔离

当前方案见 [无碰撞火区与传送射线](FireBarrierOutdoor.md)。下层火焰没有物理碰撞体，不参与站立净空检查，也不再对起点到终点执行人体扫掠或对头显位移进行回拉。

数学火区顶部仍在最近上方 FloorSlab / Landing / HalfLanding 板底下 5cm 截止。传送只检查右手到最近真实命中点的射线线段；射线命中上层地板后停止检测，下层火焰不会使上层地板无效。若射线本身确实穿过火区，仍拒绝传送。

FloorSeparationValidation.txt 覆盖实际 Trace 拒绝穿火、贴边/内部起点检测、墙后火区排除、绕开火区的正常射线、上层地板判定及真实 Provider 位移、扑灭前后限制。旧实体守卫与下部一米灭火方案已移除，根部灭火与 3 秒计时保留。
