# 四层教学楼及配套设施场景规划

状态：首版场景文件与离线三维预览已生成；Unity 实际渲染、场景文字与两条疏散路线的物理采样检查已通过。后续细化仍参考本规划，完整玩家操作与 VR 验证待完成。

适用工程：Unity 2022.3.62f3，Campus Emergency Preparedness VR。

## 1. 场景目标

搭建一栋四层虚构教学楼，支持玩家从教室出发，识别疏散方向，经楼梯撤离到室外集合点。场景需要支持普通路线熟悉练习，以及一条路线受到烟雾影响时的路线选择练习。

首版范围为教学楼内部、一部贯通四层的普通客梯、每层卫生间、消防与导向设施、必要的建筑外立面、出口前场地和集合点。优先完成能行走、能辨认、能接入玩法的空间。

## 2. 建筑布局与尺寸建议

采用长条形建筑、中央走廊、走廊两侧房间、东西两端各一座疏散楼梯的布局。楼梯 A 和 B 都从四楼连续通向一楼，并在一楼设置可通向室外的出口。

电梯布置在走廊中段北侧，四层的电梯井和厅门位置上下对齐。候梯区向北侧房间区域内凹，使用部分功能房间面积，保持中央走廊约 3 米的通行宽度。卫生间组布置在靠近楼梯 B 的服务区域，门口与楼梯入口错开。

| 项目 | 草案尺寸或位置 |
| --- | --- |
| 建筑占地 | 约 36 × 18 米 |
| 楼层数量 | 4 层 |
| 层高 | 3.6 米，建筑主体约 14.4 米高 |
| 各层地面标高 | 一楼 0；二楼 3.6；三楼 7.2；四楼 10.8 米 |
| 中央走廊净宽 | 约 3 米 |
| 标准教室 | 约 8 × 7 米 |
| 教室门净宽 | 约 1.2 米 |
| 楼梯模块占地 | 每座约 5 × 8 米，采用双跑楼梯和中间平台 |
| 单跑楼梯净宽 | 约 1.5 米 |
| 电梯井 | 约 3 × 3 米，贯通四层 |
| 电梯轿厢 | 约 1.6 × 1.8 米，全楼共一套 |
| 电梯门净宽 | 约 1 米 |
| 候梯区 | 约 4 × 3 米，占用北侧部分房间面积 |
| 卫生间组 | 每层一组，先确定外墙、入口和基础隔间 |
| 墙体与楼板厚度 | 约 0.2 米 |
| 出口前室外场地 | 约 24 × 20 米，按整体布局调整 |
| 集合点 | 放在离开建筑后的室外场地内，位置需清晰可见 |

以上为游戏灰盒设计起点，用于统一模型比例，不作为建筑施工或规范验收参数。加入电梯和卫生间后，相邻功能房间允许缩小；教室、楼梯、门口和候梯区的最终尺寸，以玩家和 VR 移动测试结果调整。

坐标约定：Unity 的 Y 轴表示高度，X 轴沿走廊长度，Z 轴沿建筑进深。模型按 1 Unity 单位约等于 1 米制作。

## 3. 每层内容

| 楼层 | 空间配置 | 首版重点 |
| --- | --- | --- |
| 一楼 | 中央大厅、101/102 教室、值班室、电梯候梯区、卫生间、楼梯 A/B、主入口及两个楼梯出口 | 完成室内到室外的连续路线，设置楼层导览图和集合方向 |
| 二楼 | 201/202/203 教室、204 教师办公室、中央走廊、电梯候梯区、卫生间、楼梯 A/B | 201 作为基础练习起点，制作完整桌椅和门窗 |
| 三楼 | 301/302 教室、303 讨论室、304 储物间、中央走廊、电梯候梯区、卫生间、楼梯 A/B | 保持布局清楚，验证上下楼后的方向识别 |
| 四楼 | 401/402 教室、403 实验室、404 办公室、中央走廊、电梯候梯区、卫生间、楼梯 A/B | 401 作为完整撤离练习起点，预留烟雾影响路线的位置 |

二到四楼使用相同的结构布局，通过房间门牌、楼层编号和少量道具形成差异。仅 201 和 401 在首版中制作完整室内布置，其他房间先完成门牌、门窗和基础空间；是否开放由练习需求决定。

上层的空间关系为：

```text
北侧空间：     教室/功能室 1     电梯井 + 内凹候梯区     教室/功能室 2
                      ↓ 门                ↓                  ↓ 门
西侧楼梯 A ←──────────── 中央走廊 ────────────→ 东侧楼梯 B
                      ↑ 门                    ↑ 门             ↑ 门
南侧空间：     教室/功能室 3             教室/功能室 4        卫生间组
```

两座楼梯的入口都应能从走廊识别。楼层编号设置在楼梯平台及每层入口附近，帮助玩家确认当前楼层。

## 4. 配套设施及制作范围

| 设施 | 位置与数量安排 | 首版制作内容 | 玩法接入 |
| --- | --- | --- | --- |
| 普通客梯 | 全楼一部，每层一个候梯区 | 一套电梯井和轿厢、四套厅门、呼梯按钮、层数显示、停用提示 | 火灾练习中停用；平时呼梯与运行可后续接入 |
| 公共卫生间 | 每层一组，靠近楼梯 B 的服务区 | 墙体、入口标识、基础隔间和洗手台 | 首版作为环境设施 |
| 防火门 | 每层两座楼梯的入口 | 门框、门板、把手、标识和碰撞，保留开门空间 | 开关门逻辑和火灾状态由队友接入 |
| 消防器材点 | 每层两处，靠近两端楼梯，避开门口 | 灭火器、消防柜或消火栓箱及识别标识 | 器材识别或交互按练习需要接入 |
| 手动报警按钮 | 每层两端出口附近墙面 | 按钮外壳、面板和标识 | 按下后的报警声音与反馈由队友接入 |
| 应急照明与出口标识 | 走廊、转角、楼梯平台和出口 | 灯具、出口图形、方向箭头和可读材质 | 火警状态下仍需可辨认，灯光切换由队友接入 |
| 烟感与报警设备 | 走廊及重点房间顶棚或墙面 | 基础烟感、报警声光器模型 | 烟雾检测与声光反馈由队友接入 |
| 楼层导览图 | 一楼大厅及各层候梯区 | 当前楼层、当前位置、楼梯与出口路线 | 静态导览即可 |

公告栏、饮水机或自动售货机可在一楼大厅后补；空调、顶棚喷淋头和其他装饰根据剩余工作量制作。首版的卫生间以空间轮廓和识别为主。

### 电梯设计与火灾练习状态

- 电梯采用一套贯通四层的井道和一套轿厢；各层仅复制厅门、按钮、层数显示和提示标识。
- 厅门、轿厢门、按钮和显示面板分别建模，方便后续挂接动画与交互。
- 当前疏散练习按普通客梯设计，火警状态下不可乘用，厅门保持关闭，按钮附近明确显示停用原因和楼梯指引。
- 使用简明英文提示，例如 `Do not use the lift in case of fire. Use the stairs.`，配合图形标识；点击按钮时的反馈交给玩法模块实现。
- 保留门后井道的碰撞边界；启用开门交互前，必须确认轿厢已在该层且玩家不能进入空井道。
- 如果后续加入正常探索模式，再接入呼梯、门动画、上下运行和楼层选择。先约定轿厢运行与 VR 玩家移动的配合方式。

消防器材的存在不表示玩家必须灭火；三个首版练习的完成目标仍为撤离到集合点。

## 5. 三个练习场景

| 练习 | 起点 | 路线与场景要求 |
| --- | --- | --- |
| 基础熟悉 | 二楼 201 | 教室 → 走廊 → 任一楼梯 → 一楼出口 → 集合点 |
| 完整撤离 | 四楼 401 | 经过四、三、二、一楼连续楼梯，最终到达集合点 |
| 路线选择 | 四楼 401 | 四楼走廊的一段受烟雾影响；从起点到另一座楼梯保留可达路线 |

烟雾和火焰使用可启用的区域承载，便于同一场景复用。场景搭建时先标记区域，具体触发、提示、判定和效果由玩法模块接入。

路线选择练习应验证玩家能识别受影响的路线，并找到仍可使用的路线；不要仅靠知道地图布局才能完成。玩家到达任一室外出口后，都需要能够继续到达集合点。

三个练习均使用电梯火警停用状态。电梯入口应能被玩家发现，停用提示与通向楼梯的导向应清楚，支持学习火灾时使用楼梯撤离。

## 6. Unity 场景组织

│   ├── Floor_02
│   ├── Floor_03
│   ├── Floor_04
│   ├── Stairwell_A
│   ├── Stairwell_B
│   └── Elevator
│       ├── Shaft
│       └── Cabin

│   └── AssemblyPointVisual

├── Lighting

    ├── Spawn_F02_201
    ├── Spawn_F04_401
    ├── Hazard_F04_Corridor
    ├── Exit_Main
    ├── Exit_A
    ├── Exit_B

    ├── Elevator_F03

`Stairwell_A/B` 和 `Elevator` 独立于楼层，避免复制楼层时重复创建楼梯、电梯井或轿厢。每层节点内部放置该层的电梯厅门、候梯区、卫生间和消防设施。`GameplayAnchors` 中使用空物体标记位置，命名供团队约定；它们本身不提供玩法逻辑。报警和消防器材标记仅展示二楼 A 端的命名示例，实际按各层位置设置。

可复用部件优先制作成 Prefab：墙段、带门洞墙段、窗墙、教室门、防火门、双跑楼梯模块、电梯厅门与按钮组、卫生间组、消防器材点、报警按钮、应急灯、出口标识、楼层导览图、课桌椅组。二到四楼共用标准楼层结构，不同门牌和摆设使用实例配置。

## 7. 搭建顺序与阶段验收

| 阶段 | 工作内容 | 完成标准 |
| --- | --- | --- |
| 1. 一层原型 | 用 Cube 搭标准上层的地板、墙、教室、门洞和走廊，预留电梯与卫生间，并制作一段层间楼梯 | 玩家能通过门口、转角和楼梯，候梯区不占走廊通行宽度 |
| 2. 四层灰盒 | 复用标准结构，搭好四层、两座完整楼梯和贯通井道，加入一楼出口、室外地面 | 从四楼沿 A/B 两条路线都能走到室外，各层电梯厅门位置对齐 |
| 3. 配套设施与导向 | 制作电梯、卫生间、防火门、消防器材、报警按钮、应急灯和各类标识 | 设施位置合理，电梯火警停用原因明确，疏散方向可辨认 |
| 4. 重点装修 | 完成 201/401、大厅、走廊、楼梯间和必要外立面 | 场景有教学楼特征，道具不挡疏散路线 |
| 5. 玩法接入 | 提供起点、危险区域、门、电梯按钮、报警按钮、出口和集合点位置 | 队友能在同一场景中运行三个练习，设施交互反馈与状态一致 |
| 6. VR 验证 | 在目标设备上检查移动方式、碰撞、设施操作距离、标识可读性和性能 | 完整撤离流程可运行，移动和画面达到团队确定的目标 |

使用基础 Cube 完成灰盒即可。需要更复杂门洞或楼梯网格时，再决定是否采用 ProBuilder；首版不依赖额外建模插件。

## 8. 场景与玩法分工

| 内容 | 场景搭建负责 | 玩法负责或共同确认 |
| --- | --- | --- |
| 建筑与家具 | 模型、材质、空间布局、静态碰撞 | 玩家尺寸与可通过范围共同验证 |
| 门 | 门框、门板、铰链位置、门口空间 | 开关门交互、是否可用的状态与反馈 |
| 烟雾与火源 | 预留位置及区域大小 | 效果、触发时机、路线状态和提示 |
| 楼梯 | 台阶、平台、扶手、连续空间 | VR 连续移动或传送的支持方式 |
| 电梯 | 井道、轿厢、各层厅门、按钮、显示面板和火警提示 | 火警停用反馈；后续正常运行、动画与 VR 玩家移动配合 |
| 消防与报警设施 | 消防柜、灭火器、按钮、报警器和安装位置 | 是否可交互、触发报警、声音和提示 |
| 卫生间与生活设施 | 空间轮廓、基础模型和标识 | 首版无必需玩法逻辑 |
| 标识 | 出口、楼层、方向和房间标识 | 检查标识与练习中可用路线是否一致 |
| 集合点 | 室外场地及视觉标识 | 到达判定和练习结束逻辑 |

项目面向国际学生，标识优先采用通用图形配合简明英文；关键标识在实际头显观看距离下验证可读性。

## 9. 首版完成清单

- 四层教学楼、两座连续楼梯和室外集合点已完成。
- 一部电梯的井道与轿厢、四层厅门和候梯区已完成，位置上下对齐。
- 电梯火警停用提示可读，玩家不能通过电梯撤离或进入空井道。
- 每层卫生间可识别；消防器材、报警按钮、应急照明与防火门已布置。
- 201/401 可作为玩家起点，其门口、走廊和楼梯均可通过。
- A/B 两条路线分别验证四楼到室外的连通性。
- 一楼主入口和楼梯出口可辨认，出口后能继续到达集合点。
- 楼层编号、房间编号、疏散方向和集合点标识与布局一致。
- 家具、装饰和门板不会造成意外堵路或卡住。
- 候梯区、消防柜和卫生间门口没有占用预定走廊宽度或遮挡楼梯入口。
- 路线选择练习的危险区域与剩余可达路线已共同检查。
- 在团队选定的 VR 设备和移动方式下完成一次全程测试。

首版暂不安排其他教学楼、宿舍、完整校园、NPC 人群或全楼精细房间装修。优先把四层楼的疏散体验做完整。
